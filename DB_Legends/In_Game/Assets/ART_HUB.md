## Integration map

- Root `README.md`: hero, cover, team core, roadmap, and Art Hub entry.
- `README_DE.md` / `README_EN.md`: hero, cover, visual gallery, and Art Hub entry.
- `PROFILE.md`: repository hero, architecture, and pipeline.
- `DB_Legends/In_Game/README*`: In-Game visual entry point.
- `Bilderbuch/`: book-oriented documentation using the cover identity.

## Art direction

Dark sci-fi / cyber-anime documentation. Blue and violet convey energy and navigation; gold highlights LEGEND LIMITED; red/green/purple labels represent team-color context.

The artwork functions as documentation UI. Major illustrations have descriptive alt text at their consuming README locations.
