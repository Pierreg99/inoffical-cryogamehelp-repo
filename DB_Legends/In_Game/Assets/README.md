# DB Legends In-Game Assets

## Visuelle Quellen

Die Assets sind bewusst als einfache, versionierbare SVG-Dateien angelegt. Dadurch bleiben sie ohne externe Fonts, CDN oder Build-System in GitHub nutzbar.

### Enthalten

- `team-core.svg` — 3er-Core mit Rollen und Farben
- `meta-flow.svg` — Matchplan von Opening bis Endgame
- `rank-roadmap.svg` — Platinum → Diamond → Legends League
- `book-cover.svg` — deutscher Guide-Coverbanner

## Designsystem

- Dunkler Sci-Fi-Hintergrund
- Blau/Violett/Pink als Energie-Akzente
- Gold für LEGEND LIMITED
- Klare Farbkennzeichnung für BLU/PUR/RED
- Hoher Kontrast und lesbare Beschriftung

## Copyright-Hinweis

Die SVGs sind neu erstellte Infografik-/Dokumentationsgrafiken. Sie sind nicht als Ersatz für offizielle Spielgrafiken gedacht.

Die im Workspace erzeugte gerenderte Leitgrafik dient als visuelle Referenz für die Dokumentation.
