## Deutsch

CRYOGAMEHELP uses a shared **cyber-sci-fi game-hub** visual system while preserving individual game identities. Visuals support navigation, build comprehension, comparison and storytelling.

### Interactive presentation

The `docs/` layer is the interactive presentation surface. It provides game filters, visual cards, a Team & Deck Builder, searchable unit/card pickers, editable slots, build stats, guide modals, theme switching and direct module navigation.

### Design rules

1. Shared shell, individual game identity.
2. Descriptive alternative text for important imagery.
3. Important information also exists as text or tables.
4. Prefer SVG for diagrams, matrices, roadmaps and UI-like documentation.
5. Do not present fan art or generated artwork as official game assets.

## English

CRYOGAMEHELP uses one **universal visual language** while allowing game modules to retain their own presentation. The interactive `docs/` layer turns those assets into a navigable visual game hub.

### Rights

Original repository diagrams, layouts and SVG artwork are documentation assets. Game names, logos, characters, screenshots and proprietary assets remain with their respective rights holders. See `LICENSE.md`.
