# Universal Game Art System

## Purpose

The `GAMES/Assets/` layer contains repository-wide visual infrastructure. Game-specific art remains inside each module so visual identity can evolve independently.

## Core asset

- `universal-game-hub.svg` — multi-game hero and architecture map

## Visual rules

- dark, high-contrast documentation shell
- one shared navigation language
- game-specific accent systems where useful
- descriptive SVG titles/descriptions and README alt text
- no external fonts, CDNs or required build systems
- important information remains available as text

## Game modules

- `DB_Legends/In_Game/Assets/` — existing DB Legends art system
- `GAMES/Pokemon_TCG_Pocket/` — collection / deck visuals
- `GAMES/Pokemon_TCG_Live/` — deck / competitive visuals
- `GAMES/Pokemon_GO/` — raid / GBL / progression visuals
