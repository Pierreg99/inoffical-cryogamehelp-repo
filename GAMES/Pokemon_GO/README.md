# Pokémon GO

Mobile location-based Pokémon game module covering catching, research, raids, Gyms, GO Battle League, events, collection planning and live-service analysis.

The official Pokémon site describes Pokémon GO as an iPhone/Android experience that connects real-world locations with Pokémon encounters; Pokémon Support notes that the game is maintained by Niantic. citeturn810788search7turn810788search5

## Module scope

- Catching and encounter strategy
- Pokédex / collection planning
- Raids and counters
- Gyms and item loops
- GO Battle League
- Events, bonuses and rotations
- Resource and progression planning
- DE/EN reports and visual trackers
