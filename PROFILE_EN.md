## Project identity

**CRYOGAMEHELP** is a modular, unofficial gaming knowledge repository for multiple games. Each game keeps its own mechanics and terminology while sharing a common documentation architecture.

## Active modules

| Module | Content |
|---|---|
| `DB_Legends/` | PvP · Teams · Equipment · Picture Book · Meta |
| `GAMES/Pokemon_TCG_Pocket/` | Collection · 20-card decks · battles · expansions |
| `GAMES/Pokemon_TCG_Live/` | Deck building · legality · ladder · competitive play |
| `GAMES/Pokemon_GO/` | Catching · raids · GO Battle League · events |

## Universal layers

**Overview → Guides → Builds → Meta → Progression → Events → Assets → Reports**

## Quality

- Source-backed facts separated from strategic judgement
- Timestamped live-service snapshots
- DE/EN navigation
- Visual-first but never image-dependent
- SVG-first diagrams and roadmaps
- No claim of official affiliation

## Extensibility

New games are added through `GAMES/GAME_MODULE_TEMPLATE.md` without restructuring existing modules.
